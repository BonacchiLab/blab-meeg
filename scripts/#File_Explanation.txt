# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#                        
# PREPROCESSING PIPELINE MEEG (5 runs) #        
# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#

# Structure (created by create_output_folders):
#   {subject}_Preproc/
#   ├── 00_badch_maxwell/
#   ├── 01_prep_pipeline/
#   ├── 02_artifact_annotations/
#   ├── 03_ica/
#   └── 04_epochs_FINAL/
#
#   {subject}_Docs/      # HTML reports, CSV files, JSON files

# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# Step 00 – Bad channels + Maxwell filtering (MEG) #
# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# INPUT:
#   - raw fifs: {subject}_EXP1_MEEG/{subject}_MEEG_1_DurR[1-5].fif
#   - cal_file: {subject}/metadata/.../calibration_meg.dat
#   - ct_file:  {subject}/metadata/.../crosstalk_meg.fif
# PREPROCESSING:
#   - find_bad_channels_maxwell (noisy + flat + scores)
#   - maxwell_filter (SSS)
# OUTPUT (save_outputs=True):
#   - /00_badch_maxwell/{subject}_badch_maxwell_{durN}.fif
#   - /Docs/00_badch_maxwell_report.html
#   - /Docs/00_badch_maxwell_scores.csv
#   - /Docs/00_badch_maxwell_info.json

# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# Step 01 – PREP pipeline (EEG only) #
# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# INPUT:
#   - files generated in STEP 00:
#     /00_badch_maxwell/{subject}_badch_maxwell_{durN}.fif
# PROCESSING:
#   - extracts EEG data and applies PrepPipeline
#     (line-noise removal, rereferencing,
#     bad-channel detection using RANSAC,
#     channel interpolation)
#   - reintegrates cleaned EEG into the MEG dataset
#     (MEG remains unchanged)
# OUTPUT:
#   - /01_prep_pipeline/{subject}_01_prep_pipeline_{durN}.fif
#   - /Docs/01_prep_pipeline_report.html
#   - /Docs/01_prep_pipeline_info.json

# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# Step 02 – Artifact detection (muscle, blink, saccades) # 
# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# INPUT:
#   - files generated in STEP 01:
#     /01_prep_pipeline/{subject}_01_prep_pipeline_{durN}.fif
# PROCESSING:
#   - muscle artifacts: annotate_muscle_zscore (110-140 Hz)
#   - eye blinks: find_eog_events + fixed annotations
#   - breaks: annotate_break (long periods without events)
#   - merges all annotations into the raw object
# OUTPUT:
#   - /02_artifact_annotations/{subject}_02_artifact_annotations_{durN}.fif
#   - /Docs/02_artifact_annotations_times.csv          # timing information for each detected artifact
#   - /Docs/02_artifact_annotations_report.html

# *#*#*#*#*#*#*#*#*#*#*#*#
# Step 3A – ICA training #
# *#*#*#*#*#*#*#*#*#*#*#*#
# INPUT:
#   - files generated in STEP 02:
#     /02_artifact_annotations/{subject}_02_artifact_annotations_{durN}.fif
# PROCESSING:
#   - loads data, selects MEG + EEG + EOG + ECG channels
#   - applies 1-40 Hz filtering and resamples to 250 Hz
#   - concatenates all runs into a single raw dataset
#     for ICA training
#   - trains separate ICA decompositions for MEG and EEG
#     (FastICA, 99% explained variance)
#   - automatically identifies EOG and ECG components
#     through correlation analysis
# OUTPUT:
#   - /03_ica/{subject}_03_ica_train_file.fif     # concatenated raw dataset used for ICA training
#   - /03_ica/{subject}_ica_meg.fif               # trained MEG ICA object
#   - /03_ica/{subject}_ica_eeg.fif               # trained EEG ICA object
#   - /Docs/{subject}_ica_comps_to_remove.json    # automatically detected ICA components
#   - /Docs/03_ica_report.html                    # ICA diagnostic report
#

# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# Extra step  – ICA manual inspection  #
# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# After ICA training, the user must manually inspect
# the components ( manual_ica_review.py) and edit the 
# JSON (/Docs/{subject}_ica_comps_to_remove.json)file 
# by adding selected components to:
# "manual": {
#     "eog": [...],
#     "ecg": [...]
# }

# *#*#*#*#*#*#*#*#*#*#*#
# Step 3B – ICA apply  #
# *#*#*#*#*#*#*#*#*#*#*#
# INPUT:
#   - files from STEP 02 (annotated runs)
#   - trained ICA objects: /03_ica/*ica_*.fif
#   - JSON file containing components selected
#     for removal after manual inspection
# PROCESSING:
#   - loads ICA solutions and JSON file
#   - combines automatic and manual component selections
#   - applies ICA to each run independently
#   - concatenates the five cleaned runs
# OUTPUT:
#   - /03_ica/{subject}_03_ica_concat.fif       # concatenated dataset after ICA cleaning
#   - individual ICA-cleaned runs are not saved
#   - /Docs/03_ica_completed_report.htm         # ICA properties report


# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# step 04 – Epoching e baseline  #
# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
# INPUT:
#   - Concatenated file from step 3b:
#     /03_ica/{subject}_03_ica_concat.fif
# PROCESSING:
#   - finds events (STI101) and extracts events 1-80
#   - creates epochs (tmin=-0.9 s, tmax=1.5 s)
#   - rejects epochs overlapping with annotations
#   - applies baseline correction (-0.9 to 0 s)
#   - removes bad epochs using predefined rejection criteria
#   - generates metadata
#       (category, orientation, duration,
#        relevance, and sex)
# OUTPUT:
#   - /04_epochs_FINAL/{subject}_04_epochs_FINAL.fif
#   - /Docs/04_epochs_report.html
#   - /Docs/metadata.csv

# NOTES ON THE COMPLETE WORKFLOW (master pipeline) #
# *#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#*#
#
# - The preprocessing workflow is divided into two parts:
#
#     Part 1:
#         STEP 00 Bad_channels + Maxwell filter
#         STEP 01 Prep Pipeline
#         STEP 02 Artifact Annotation
#         STEP 03A (ICA training)   
#
#     Part 2:
#         STEP 03B (ICA application)
#         STEP 04 (epoching)
#
# - Manual inspection of the ICA components is required
#   between Part 1 and Part 2.
#
# - Each processing step stores its outputs in dedicated
#   folders, making it possible to restart the workflow
#   from any stage if necessary.
